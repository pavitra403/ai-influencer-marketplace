# AI Influencer Marketplace (Two-Sided Platform)

## Overview
A two-sided marketplace platform where brands can post campaigns and influencers can apply.  
The system supports influencer matching based on niche, engagement, and audience demographics.

## Features
- Brand & Influencer Authentication
- Campaign Creation (Brand)
- Campaign Listing (Influencer)
- Apply to Campaign
- AI-based Matching (Basic scoring logic)
- Admin Monitoring (Future scope)

## Tech Stack
- Frontend: React
- Backend: Firebase / Node.js (Planned)
- Database: Firestore

## Status
Currently in development. Initial setup completed.
